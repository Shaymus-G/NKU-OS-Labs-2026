# 自动地址查询演示：实际实施前规格

来源：用户要求完成教师提及的扩展，课程文字记录 00:43:13 提出基于智能体的地址查询与单步调试演示可贡献课件。本规格按用户随后提供的助教四段式组织，不是另一个模型的伪造对话。

## Prompt

新增可运行工具，启动本机已有 QEMU 和 GDB，自动在分页启用前后停止、读取本次 ELF 的真实 kern_init 和根页表，并对实际地址做 Sv39 查表解释。保存 JSON 和文字证据，准备可供课程演示复用的命令及说明。不要改固件或内核页表，不替代或伪造 A 的宿主 QEMU TLB 调试。

## Rely

依赖现有 RISC-V GDB 包装器、QEMU GDB stub、当前 bin/kernel 符号、entry.S 的 satp 写指令及 Sv39 PTE 语义。通过本机128MiB启动映射读根页表，但不得硬编码旧根页表/入口数值。地址转换计算与客体实际执行必须明确区分。

## Guarantee

交付独立页表解码/遍历函数、可交互 GDB 命令、自动运行脚本和离线边界测试。输出原始 satp、地址、各级索引和 PTE、叶子层级/大小、R/W/X/U/G/A/D 标志、物理地址或错误；提供分页前后寄存器和真实单步过程。

## Specification

成功查询时从当前 satp 得到模式与根物理地址，检查规范地址、PTE 有效性、非法 W/R 组合及大页低 PPN 对齐；遇叶子提前结束，不能总声称走三级。未映射、非法大页、非规范地址、权限组合错误明确输出错误。Bare 模式 VA=PA，并注明特权语义边界。工具只做结构化地址推导，不声称完整模拟 MPRV/SUM/MXR、PMP、所有异常或 QEMU 软件 TLB。自动脚本只终止自己的 QEMU 进程组，不结束其他人的调试会话。
