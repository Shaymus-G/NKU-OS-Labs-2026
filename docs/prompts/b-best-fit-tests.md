Codex 在实现前采用的测试规格如下。这是本次执行采用的约束记录，不是学生另外发送的提示词，也没有调用第二个模型。

- 新增独立的 C 测试文件，通过现有 alloc_pages/free_pages/nr_free_pages 接口操作真实内核分配器，不复制算法、不伪造 PASS。
- 教师 basic_check()、best_fit_check()、评分断言及 A 的 page_init() 保持原样。增加 check 包装函数，先执行原教师自检，再执行新增测试。
- 测试运行于启动自检阶段，要求初始化后有一个至少 32 页的连续空闲区。通过分配接口临时取出全部空闲页，只在其中 32 页构造测试布局，其余页保持已分配，排除其他候选块干扰。
- 分别检查：多个候选块中选最小足够块、精确匹配、同大小块按低地址选择、拆分余块、向前合并、向后合并、填补中间空隙并同时合并两侧、碎片和总量不足失败、反复分配释放及最终完整恢复。
- 断言应核对实际返回指针、空闲页计数、PageReserved、PageProperty、块头 property 和引用计数。每个用例结束时收回该用例释放的全部页，恢复到测试区完全已分配状态。
- 最后归还整个临时区，核对初始空闲块地址、长度、总空闲页数及保留页数量恢复。
- 运行 clean build、QEMU 和教师 make grade，保存真实日志。失败时不把未通过结果写为成功。
- 当前测试针对 A 的单段初始化和 Best-Fit，不声明适用于 Buddy，也不测试重复释放或非法地址。
