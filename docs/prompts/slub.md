# SLUB 扩展：本轮实际规格与测试记录

来源：用户要求“选做项我们都要做”“老师提到的可扩展的部分也都要做”，实际会话由同一助手连续实现和验证，不虚构独立模型对话。编码前规格保存在 `docs/notes/extension-plan.md`，本文件补充实际使用的细节和判据。

## 场景与输入

基于已有 A 初始化、B Best-Fit 和 C Buddy，新增小对象分配层。原有 Page、pmm_manager 和教师检查保持接口与算法不变；现有工具链直接激活，不安装软件或修改 QEMU 包装器。

## 输出目标

提供命名缓存与通用 kmalloc/kfree，真实多个小对象共享一页。页内元数据和对象内空闲链、位图校验、partial/full/empty 转移、构造回调、空页 shrink、大对象按底层原始请求释放。仅通过 LAB2_EXTENSIONS 宏接入正常启动后的独立检查。

## 约束

单核、串行使用；不是 Linux SLUB 多核版本。默认模式不能运行扩展测试。缓存对齐可控、失败不能泄漏页；错误缓存/双重/内部指针释放断言。正常与异常检查必须分开启动。所有历史日志和图片保持原样，新代码改变布局时保存新证据。

## 验收与实际使用的测试规格

分别以 Best-Fit/Buddy 为页分配器：验证 37 字节记录与 64 字节对齐、对象复用、构造次数、两页数据不重叠、缓存状态转换、不能销毁活对象缓存、大小类边界、大对象原始页数契约、64 对象共用一页、1024 混合操作、描述符耗尽与真正页耗尽。全部释放加 shrink 后应恢复运行开始的空闲页数。三个非法释放用例各自启动，要求明确 case 和断言 panic，不能在正常自检里混入预期故障。

## 后续按助教 Prompt / Rely / Guarantee / Specification 复核

用户在本轮编码后补充了助教讲解。以下是依照该格式进行的后续规格复核，不改写前面的真实开发过程。

### Prompt

在 kern/mm/slub.c/.h 与 slub_test.c 完成页上小对象分配、缓存回收和独立验证。实际修改文件；默认管理器、页接口和教师测试不改。用两种页分配器各自运行，保存成功和预期失败证据。

### Rely

最小依赖为 pmm.h 的 alloc_pages/free_pages/nr_free_pages、Page 与物理地址换算、页大小 PGSIZE、list.h 的双向链表、串行启动上下文。不得把 Buddy 的完整块释放误当作 Best-Fit 部分区间释放。

### Guarantee

交付 slub.h 中的 cache_create/alloc/free/shrink/destroy/stats、kmalloc/kfree/ksize、slub_init/slub_check；内部元数据不作为公共接口。输出模式、自检结果、前后页数及实际失败契约。

### Specification

初始化后缓存可创建。合法对象尺寸和对齐时返回可用缓存；无法容纳或描述符耗尽返回 NULL 且不消耗页。对象分配成功时不重叠、按请求对齐、活计数增加；页不足返回 NULL 且缓存状态不变。释放要求同缓存、对象起点及已分配状态，否则断言；合法释放减少活计数，可复用。销毁有活对象的缓存返回 false；shrink 仅收回空页。全部对象释放和 shrink 后应恢复初始物理页数，由断言核验。
