# page_init() 设计与 AI 辅助记录

## 功能规格

实现 kern/mm/pmm.c 中的：

static void page_init(void);

输入来源：

- get_memory_base()：设备树报告的内存起始物理地址。
- get_memory_size()：设备树报告的内存大小。
- end：内核镜像末端虚拟地址。
- 框架提供的页大小、内存管理上限和虚实地址偏移。

需要设置的全局变量：

- va_pa_offset
- npage
- pages

实现要求：

1. 检查设备树内存信息是否合法。
2. 根据框架支持范围确定可管理的物理内存边界。
3. 在内核末端之后按页对齐放置 Page 描述符数组。
4. 在写入数组之前检查它能否完整放入内存。
5. 初始化描述符，并先将页面设置为保留。
6. 排除 OpenSBI、内核、描述符数组和对齐空隙。
7. 将剩余完整页面通过 init_memmap() 交给分配器。
8. 输出内存布局，供运行和调试核对。

关键约束：

- 区分虚拟地址、物理地址、物理页号、Page 指针。
- npage 是物理页号上界。
- npage - nbase 是描述符需要覆盖的页数。
- 无效内存信息应停止初始化。
- 没有完整空闲页时不调用 init_memmap()。
- 不修改教师提供的检查函数。
