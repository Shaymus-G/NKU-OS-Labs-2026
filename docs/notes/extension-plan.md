## 实现前使用的扩展规格

SLUB 在已有页分配器之上工作，不改 Page 或 pmm_manager 接口。以单核教学 SLUB 风格实现每页元数据及对象内空闲链；提供缓存、对齐、构造回调、空页回收与通用 kmalloc/kfree，明确不等同于 Linux 多核 SLUB。小对象必须复用物理页，不以每对象分配整页冒充对象分配器。接口拒绝错误尺寸/对齐；非法释放断言，正常与预期失败测试分开。

DTB 功能必须从传入 blob 的真实长度、结构块和字符串块范围判断合法性，禁止未界定 strlen 或无界 token 遍历。支持本框架的一段连续内存和 1/2 个 cell 编码，明确多内存 bank 的支持边界，不猜测返回地址。实际启动记录 DTB 报告范围和框架裁剪范围。

地址查询工具必须使用本次 ELF 符号和实时页表，不能硬编码旧 kern_init/根页表地址。输出原始 satp、每级索引/PTE/叶子级别、物理地址和判据；离线计算与真实客体执行/宿主 TLB 观察须区分。
